# Movie Project

A simple responsive web project showcasing top movies with login and contact forms.

## Features

- Modern responsive design
- Header with project title
- Navigation bar
- Hero section
- Top movies section (dynamically loaded via JavaScript)
- Login form
- Contact form
- Footer

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Open `index.html` in your web browser.

## Git Commands Demo

This repository includes a demonstration of common Git commands:

1. Initialize repository: `git init`
2. Check status: `git status`
3. Add files: `git add .`
4. Commit changes: `git commit -m "Initial commit"`
5. View commit history: `git log`
6. Create a branch: `git branch feature-login`
7. Switch to branch: `git switch feature-login`
8. Make changes and commit
9. Merge branch: `git switch main` then `git merge feature-login`
10. Push to remote: `git push origin main`

## Testing with Postman

We use Postman to test API endpoints from [JSONPlaceholder](https://jsonplaceholder.typicode.com/):

1. Successful request: `GET https://jsonplaceholder.typicode.com/posts/1`
2. Failed request: `GET https://jsonplaceholder.typicode.com/posts/999999`
